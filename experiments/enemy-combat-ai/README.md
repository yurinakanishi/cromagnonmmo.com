# SDP行動選択のローカル・スモールテスト

実施日: 2026-11-01。Python 3.14.2、標準ライブラリのみ。API・LLM・ネットワーク・ゲーム本体の起動なし。

## 実行

```sh
python3 experiments/enemy-combat-ai/small_test.py
```

同じディレクトリの `results.json` を更新する。ゲームやセーブには触れない。

## 今回試した式

```text
Q = 0.4×人格 + 0.2×心理 + 0.4×観測状況
適合度 = dot(Q, normalize(戦術ベクトル)) / sqrt(4)
評価 = 適合度 + 学習補正[-0.08,0.08]
                + ヘイト補正[0,0.08]
                + 現対象の継続補正0.03
```

闘争・保全・警戒・好機の4軸。戦術には正負の重みを使う。実行不可能な候補は評価前に除外。同点は対象ID・戦術名の順で決定する。係数と候補ベクトルは、この実験用に手で設定した仮値であり最適化済みではない。

## 実測結果

| 条件 | 選択 | 判定 |
| --- | --- | --- |
| 同じ場面・闘争的な人格 | 攻撃 | PASS |
| 同じ場面・慎重な人格 | 退避 | PASS |
| 闘争的でも包囲されている | 退避 | PASS |
| 攻撃の隙を観測 | 反撃 | PASS |
| 不可能な対象に極端なヘイト | 合法な対象を選択 | PASS |
| 全候補が不可能 | 意図なし（ゲーム側の待機・帰還等は未実装） | PASS |
| 同条件でBへのヘイトが高い | Bを選択 | PASS |
| 現対象AとBに小さなヘイト差 | Aを継続 | PASS |
| 反撃に過去失敗の補正があるが、現在は大きな隙 | 反撃を再選択 | PASS |

固定seedで生成した1,000条件でも、不可能な候補の排除、スコアの有限性、補正の上限、入力候補の並べ替えに対する選択の再現性を確認。NaN入力の拒否も確認した。これらはゲームで勝てることの検証ではない。

人格だけを変え、心理と状況を全軸0.8とした比較では、旧方式の加算・clampは両人格とも `(1,1,1,1)` になった。同じ戦術ベクトルを使う加重平均版は、闘争型 `(0.88,0.52,0.52,0.52)`、慎重型 `(0.52,0.88,0.84,0.52)` と区別を保持した。この比較は集約式だけの比較で、旧提案全体との性能比較ではない。

## 判定と限界

小さな数値選択器として成立する。旧集約式が人格差を失う具体例も再現できた。ただし、手で設定したシナリオに対する確認であり、任意の戦況で適切に判断する証明ではない。

- 学習補正は手で与えた値。経験からの更新、忘却、再学習の循環は未実装。
- ヘイトも入力値。命中による増加・時間減衰・イベント重複防止は未実装。
- 状況ベクトルと合法性は入力。ゲームの位置・攻撃動作から抽出する処理は未実装。
- 継続補正のみ。最低継続時間・切替閾値・多人数の長時間安定性は未検証。
- ランク別記憶、保存復元、マルチ同期、既存戦闘計算との非干渉は未検証。
- 実ゲームの処理時間・負荷・バランスは測定していない。

既存PR素案の式はこの実験とは異なる。今回の結果だけで正式仕様へ自動採用していない。
