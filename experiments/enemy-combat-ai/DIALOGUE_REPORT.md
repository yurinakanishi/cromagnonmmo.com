# 記憶に基づく語りかけのローカル試験

実施日: 2026-11-01。Python標準ライブラリのみ。API・LLM・ネットワーク・ゲーム本体は使用していない。

## 結果

22項目すべてPASS。実際にJSONファイルへ前回戦闘の観測を保存し、新しいオブジェクトで読戻して再戦を開始した。

| 条件 | 結果 |
| --- | --- |
| 初対面で突きを観測 | 記憶を示す台詞なし |
| 保存・読戻し後、同一IDが再び突く | 「また、その間合いか。」 |
| 保存・読戻し後、同一IDが側面攻撃へ変える | 「……前とは違うな。」 |
| 別IDの相手 | 台詞なし。表示名は判定に使わない |
| 別の部屋・セッション、別ボス | 元の個人記憶を流用しない |
| 過去記録なし・低ランクで記憶を消去 | 台詞なし |
| 過去または現在の観測が不足・曖昧 | 台詞なし |
| 同じ戦闘での再選択・再読込み | 発話を繰り返さない |
| 複数人が存在 | 初対面には出さず、既知の相手の観測だけで選ぶ |
| 発話能力なし | 台詞なし |

発話イベントには、宛先ID、前回・今回の戦闘ID、根拠となる過去・現在の観測IDを含める。今回の戦闘を前回として誤用しないことと、同じ観測IDの重複を観測回数に加算しないことも確認した。

## 試験用の規則

- 観測は `thrust / flank / feint` の合成イベント。過去と現在それぞれ3件以上、同一種類が75%以上の場合に傾向とみなす。
- 認識できた同一相手の直近の戦闘記録を参照する。
- 高ランクのみ戦闘終了時に記録を残し、低ランクは残さない。
- 同一戦闘につき記憶台詞は最大1回。発話済み記録も保存する。
- 保持は過去16戦闘・発話済み64戦闘まで。これらは実験用の仮値。
- 台詞選択で戦闘の数値や行動は変更しない。ただし本体へ未接続のため、実ゲームへの非干渉を実証したものではない。

## 前回の学習試験との関係

前回の学習記憶は戦術別の評価と回数だけで、人物IDや観測履歴を持たない。その記録から「この人物が以前突いてきた」と推測してはいけないため、今回は別の明示的な観測記録を作成した。

本試験は記憶を根拠にした定型台詞の選択と保存の確認であり、学習選択器と発話が同じ本番イベントを参照する統合試験はまだ行っていない。

## 未検証

- ゲーム内の動作から観測イベントを抽出する処理。
- マルチプレイでの宛先・配信・途中参加への実際の同期。
- 音声・画面表示・戦闘更新時間への影響。
- 原子的保存、破損ファイル検査、人物IDの本番運用。
- 保持上限から削除された古い発話の再抑制。再読込み時の抑制は保持中の同一戦闘IDについて確認した。
- 一戦闘の観測件数の上限と要約。現在は小さな合成イベント列での試験のみ。
- 一般経験による初対面への発話は未実装。この試験では個人記憶がない場合は沈黙する。
