# 感覚ベクトル・一族のヘイト共有のローカル試験

2026-11-01。Python標準ライブラリのみ。外部API、ネットワーク、ゲーム本体、実セーブを使用しない独立実験。

## 要求と確認方法

今回の依頼を、感覚ベクトルの試験、一族内のヘイト共有の試験、目視または鳴き声による招集、感覚差による反応差の4点として扱った。攻撃イベントを受けた同族の仲間が感知条件を満たすとき、観測と移動目標を得ることを確認する。相手が未識別の場合は個人へのヘイトを付けず、識別後に共有する。

```sh
python3 experiments/enemy-combat-ai/sensory_kin_test.py
```

18テストすべて成功。実行時に `sensory_kin_results.json` へ成否と4シナリオの観測・移動軌跡を保存する。

| 条件 | 実測結果 |
| --- | --- |
| 目視のみ可能 | (4,0)から攻撃観測地点(0,0)へ移動。player-Aへのヘイト0.2 |
| 鳴き声のみ感知 | (4,0)から発信地点(0,0)へ移動。攻撃者不明のためヘイトなし |
| 同じ音・鴉型の聴覚0.8 | 感知強度約0.533で反応 |
| 同じ音・視覚依存型の聴覚0.2 | 感知強度約0.133で無反応 |
| 同じ匂い・追跡獣型の嗅覚0.9 | 感知強度0.45で痕跡地点へ移動 |
| 同じ匂い・鴉型の嗅覚0.1 | 感知強度0.05で無反応 |
| 4個体への同じ通知 | 目視可能・聴覚のみの同族2体が集合。範囲外・別一族の2体は移動しない |
| 同一攻撃を視覚・聴覚で10回通知 | ヘイトは0.2のまま。重複加算なし |
| 音で集合後に攻撃者を目視 | 目視後に初めてヘイト0.2を加算 |
| 別々の2人から攻撃 | 各攻撃者へ0.2ずつ。相手を混同しない |

感度0、刺激0、遮断、範囲外、期限切れの音・匂い、別一族、非数値の感度、ヘイト上限と減衰も確認した。視覚が遮断されても音が届けば反応する。音・匂いに試験側から攻撃者IDを混入させても観測には渡さない。移動は0.5秒ごとに最大0.5単位で、瞬間移動しないことを確認した。

## 実験の仮定と限界

- 2次元の障害物のない平面。実ゲームの経路探索・描画・衝突判定ではない。
- 感知は感度×刺激×距離減衰×伝達係数×時間減衰。閾値0.3、感覚別射程10/12/8、寿命2/2/10秒、速度1単位/秒は仮値。
- 攻撃イベントから目視刺激と警戒音を生成するが、実際の被弾・視野・壁・遮音からの抽出は未接続。遮蔽は試験が渡す係数で表す。鳴くまでの遅延や硬直は未実装。
- 嗅覚の刺激は手動配置した痕跡。匂いの生成・風・個体識別は未実装。古い痕跡が検出されなくなることは確認したが、既存の捜索目標を期限で破棄する処理は未実装。
- 一族IDは固定設定。別一族を除外するのは招集の試験範囲であり、一般の感覚が他種を検出できないという仕様ではない。
- 共有ヘイト係数0.5、上限1、毎秒0.1の減衰は仮値。音だけの招集と、識別した対象へのヘイト共有を区別する。
- 同一イベントの直接再受信は重複排除するが、中継・招集人数上限・通知頻度制限・長時間の記録容量管理は未実装。観測リストと重複排除集合はこの短い試験内で保持するだけ。
- 人格のSDP選択、学習・長期記憶、保存復元とはまだ結合していない。招集を受けると直接移動目標を設定する簡略モデル。
- マルチ同期、既存の安全圏・階位制約、戦闘計算への非干渉、実ゲームの負荷・強さ・バランスは未検証。

結論は、定義した簡略モデル内で感覚差による検出と選択的な集合・共有ヘイトが成立した、という範囲に限る。
