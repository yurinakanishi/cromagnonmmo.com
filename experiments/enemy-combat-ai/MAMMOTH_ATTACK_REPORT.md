# マンモスの牙・短距離体当たり：護衛攻撃の独立試験

2026-11-01。Python標準ライブラリのみ。本体ソース、セーブ、外部APIを使用・変更しない。

```sh
python3 experiments/enemy-combat-ai/mammoth_attack_test.py
python3 experiments/enemy-combat-ai/mammoth_herd_test.py
```

追加8テスト（両攻撃・保護対象別の分岐を含む）、既存の群れモデル13テストが成功。`mammoth_attack_results.json` に成否と移動軌跡を保存する。

## 検証したこと

前回の群れモデルで認識した攻撃者と護衛役を使い、保護対象の近くでのみ攻撃を開始する。テイムは個体間の仲間関係であり、所有や無条件の服従ではない。

| 条件 | 結果 |
| --- | --- |
| 子どもへの脅威 | 牙・体当たりが各1回命中し、護衛は保護対象から2単位以内 |
| テイムした仲間への脅威 | 同じ2種類の防衛攻撃を実行し、保護対象から2単位以内 |
| 相手が逃走 | 攻撃を打ち切り、追撃で保護対象を置き去りにしない |
| 保護対象が退避 | 護衛範囲外になったら攻撃中止。攻撃より再接近を優先 |
| 予備動作 | 0.59秒時点では移動・命中なし |
| 連打要求 | 実行中と回復待ちは再開始しない。待ち時間後に有効な対象なら再開 |
| 横回避 | 固定方向のまま。横へ追尾せず空振り |
| 遮断入力 | 命中せず、体当たりの前進も停止 |
| 騎乗へ移行 | 自律攻撃を中止。プレイヤー操作を代行しない |
| 仲間・未確認の相手 | 群れ判断で攻撃対象になっていなければ攻撃開始を拒否 |

仮値は予備動作0.6秒、牙の判定0.8秒、攻撃終了1.1秒、終了後待ち0.5秒。牙はその場、体当たりは開始方向へ最大1単位進む。保護対象から2単位以内、脅威が保護対象から4単位以内という制約を、攻撃開始後も確認する。これらは実際のマンモスの身体サイズに対応した数値ではない。

通常の評価変更で予備動作や向きを書き換えない。護衛範囲逸脱、騎乗、死亡などは安全な中止条件として扱う。この独立モデルのルールを既存攻撃コードへ接続したわけではない。

最初の再攻撃試験は、体当たり後に攻撃者と同一点になり、方向を定められないため開始拒否になった。待ち時間の試験として非ゼロ距離の対象を置き直し、方向未定義の拒否条件は維持した。

## 未検証・適用限界

- 身体半径・牙の形状・アニメーション・実際のHP損害を扱わない。命中はイベント記録のみ。相手の押し出し・転倒は未実装。
- 壁は遮断フラグで入力。実地形の衝突・経路探索、途中障害物の掃引判定ではない。
- 群れ判断は開始時に一度接続。攻撃中も群れ全体を継続更新する統合試験ではない。
- 子どもとテイムした仲間は同地点の別シナリオ。離れた複数の保護対象を同時に守れることは保証しない。攻撃時の保護対象選択は試験側で指定している。
- 保護対象が瞬時に遠くへ移動した場合は距離制限を即時維持できず、攻撃中止・再接近を確認する。常に護衛できるとの主張ではない。
- 実ゲームでのテイムの獲得・保存、学習、マルチ同期、描画、バランスは未検証。

## 撤退状態との接続

群れの撤退状態では両攻撃を中止し再開始を禁止する試験を追加し、現在9テスト成功。これは独立モデルでの接続であり、実combat関数を使う別実験やゲーム更新ループには未接続。
